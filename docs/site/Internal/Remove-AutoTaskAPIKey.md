# Remove-AutoTaskAPIKey

## SYNOPSIS
Removes the Api keys from the global variables

## SYNTAX

```powershell
Remove-AutoTaskAPIKey [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
The Remove-AutoTaskAPIKey cmdlet removes the Api keys
from the global variables

## EXAMPLES

### EXAMPLE 1
```powershell
Remove-AutoTaskAPIKey
```

Removes the Api keys from the global variables
